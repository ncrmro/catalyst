# Catalyst

**An open-source platform for shipping faster.** Catalyst is an Astro site that deploys to Cloudflare Workers and pairs with a Kubernetes operator you run in your own cluster. Connect a cluster, declare resources, and let Catalyst reconcile them — no managed control plane required.

- **Deploy anywhere.** The site is a Cloudflare Worker. The operator runs in any Kubernetes cluster.
- **Bring your own cluster.** Catalyst connects to your cluster; your data and workloads stay yours.
- **Spec-driven.** Declarative resources, reviewable diffs, agent-friendly interfaces.
- **OSS-first.** MIT licensed, contributor-friendly, designed to be forked.
